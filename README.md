# ceo.skillsforu.org

黃偉翔的個人線上名片，純靜態網頁。

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 網頁內容與樣式 |
| `whang-wei-hsiang.vcf` | 「加入通訊錄」下載的聯絡人檔（手機號碼只放在這裡，頁面上不顯示） |
| `portrait-600.jpg`、`portrait-1200.jpg` | 頁面上的照片（手機、電腦各一種尺寸） |
| `og.jpg` | 分享到 LINE、Facebook 時的預覽圖 |
| `apple-touch-icon.png`、`icon-192.png` | 瀏覽器分頁與手機主畫面圖示 |
| `vercel.json` | 讓聯絡人檔用正確格式開啟 |

改完內容推送到 `main`，Vercel 會自動重新部署。
